# Title and Project Overview:-
## Project Name:-Students Performance & Prediction System
## Description:-
It welcomes the student to the Student Portal then asks to enter their name and password after which it gets the student data i.e his current marks,attendance and name then it calculates the class average marks and attendance after which it predicts the grade for the class then it tells the correlation between your attendance and your marks after that it shows your academic report which includes things like (Student Name , Attendance percentage , Current marks , Predictedd final score , Predicted final grade , class average marks and attendance ) after which it is followed up with Marks Advice vs Class Average ans at the end it displays the attendance advice.
# Project Features:-
## Common Password Check:-
Restricts access using a global predined password
## Case insensitive student lookup:-
Accepts names in any casing whether its lower case or upper case.
## Personalized Academic Report:-
Retreives and displays individual recoed detail.
## Weighted Grade Prediction System :-
Calculates a Combined performance score using 70/30 weighted formula.
## Classroom Statistics:-
Calculates real time average for marks and attendance.
## Attendance vs Performance analysis:-
Evaluates the relationship between attendance and and marks to output targeted analysis.
## Automated advice:-
Generates advice based on your attendance
